# Markit 浏览器扩展 · 安装与使用（Chrome / Edge）

> 适用于 v0.3.0 起的服务端。免上架商店，本地加载，1 分钟装好。

## 一、生成 API Token（30 秒）

1. 打开你的 Markit 网页 → 登录
2. **设置 → 扩展与 API** → 名称随意（如「我的 Chrome」）→ **生成**
3. 弹窗里那串 `mk_` 开头的 Token **立即复制**（只显示这一次）

## 二、安装扩展（Chrome 为例）

1. 把 `markit-extension-v0.4.13.zip` 解压到一个**固定位置**（如 `~/Markit扩展/`，以后不要移动）
2. 打开 `chrome://extensions/`
3. 右上角打开 **「开发者模式」**
4. 点左上角 **「加载已解压的扩展程序」** → 选择解压出来的文件夹
5. 工具栏出现 Markit 图标 → 建议点拼图图标 → **固定**到工具栏

**Edge**：同样流程，地址是 `edge://extensions/`，开发者模式在左侧栏开关。

## 三、配置（10 秒）

1. 点扩展图标 → 首次弹出配置页
2. 填：**Markit 地址**（如 `https://your-markit.example.com`）+ 刚才的 Token
3. 点「保存并测试」→ 显示 ✓ 连接成功 → 完成

## 四、日常使用

| 操作 | 效果 |
|---|---|
| **点扩展图标** | 弹出小窗并**已自动收藏当前页**；小窗里可改标题/简介再保存；关掉小窗不影响已收藏 |
| 图标右下角蓝色 **✓** | 表示当前页已在库中 |
| **右键网页** → 「收藏此页到 Markit」 | 不弹窗直接收藏 |
| **右键选中文本** → 「收藏此页（选中文本作为简介）」 | 选中的文字自动作为简介 |
| **Ctrl/Cmd + Shift + M** | 快捷键收藏（可系统通知确认） |

## 五、更新 / 卸载 / 安全

- **更新扩展**：新版解压覆盖原文件夹 → `chrome://extensions/` 里点该扩展的「刷新」按钮
- **卸载**：extensions 页面移除即可；Token 建议同时到 Markit 设置里**撤销**
- **Token 安全**：等同该账号的收藏权限（只增改书签，不能读你的密码/不能删账号）。泄露就到 设置 → 扩展与 API → 撤销重来
- NAS 上的 Markit 升级到 ≥ v0.3.0 才有本扩展的接口

## 常见问题

- **提示 Token 无效**：重新生成一个并到扩展里重新配置（弹出配置页：右键扩展图标 → 选项，或清掉后重新点图标）
- **测试连接失败**：确认地址带 `https://` 且能打开；内网地址 `http://192.168.x.x:8340` 也可用（手机/电脑同 WiFi 时）
